# CS361-Project-AI-Coloring-Book-
semester project for CS361 @ OSU

Allow users to generate via AI coloring book pages off of a given theme. Eventually allow for custom
of physical coloring books. 

Will feature database integration to track users, generated pages, orders, etc.

Will use API calls and free AI APIs (ex Grok, ChatGPT) to generate coloring pages

Optionally may allow user to generate page prompts/descriptions, which user can edit before choosing
to generate pages (depending on complexity)
